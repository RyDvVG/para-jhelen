# Para Jhelen ♡

Sitio web romántico y responsivo desarrollado en HTML, CSS y JavaScript, listo para **GitHub Pages**.

## Ver la página en tu computadora

Abre `index.html` con Chrome, Edge o Firefox. No requiere instalación.

## Personalizar la carta

En `script.js`, ubica el objeto `CARTA` al inicio del archivo. Puedes cambiar `saludo`, los textos de `parrafos` y `firma`.

En `index.html`, puedes editar los textos de la portada, las tres tarjetas y el cierre. Los colores y estilos están en `styles.css`.

## Publicarla en GitHub Pages

1. Crea un repositorio nuevo y **público** en github.com.
2. Sube a la raíz del repositorio los cuatro archivos: `index.html`, `styles.css`, `script.js` y `favicon.svg` (no es necesario subir las imágenes de vista previa).
3. Abre **Settings → Pages → Build and deployment**.
4. En *Source*, escoge **Deploy from a branch**; en *Branch*, **main**, carpeta **/(root)**, y pulsa **Save**.
5. Después de la publicación, podrás acceder a `https://TUUSUARIO.github.io/NOMBRE-REPOSITORIO/`.

La página es estática: no guarda información y no necesita backend ni base de datos. La tipografía usa Google Fonts cuando hay Internet y tiene fuentes alternativas para funcionar sin conexión.

**Privacidad:** Si lo publicas en un repositorio público, cualquier persona con el enlace podrá leer la carta, y el contenido del repositorio será público. Comparte el enlace solo si estás cómodo con ello.
